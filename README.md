# Yuanbai Li — Online Résumé

A responsive, single-page résumé for AI and medical multimodal learning roles.

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

The page is designed for GitHub Pages. Once this repository is public, select **Settings → Pages → Deploy from a branch → main → /(root)**.

## Updating

Edit `index.html` for content, `styles.css` for appearance, and replace `Yuanbai_Li_ai.pdf` with the latest résumé PDF.
